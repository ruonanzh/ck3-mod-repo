# CK3 mod workspace

The modding environment for **Crusader Kings III** (Paradox, `pdx-script` mod type). The player and the agent both use this workspace.

1. Read `docs/` for the game mechanics and the modding conventions.
2. Write each mod under `your_mods/<ModName>/`.
3. Check each mod with the `validate_mod` tool.

The repository structure and the session roles are in [AGENTS.md](AGENTS.md). The step-by-step procedure is in [`.pi/skills/`](.pi/skills/).
